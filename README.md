## About

AI, data and backend engineer based in São José dos Pinhais, PR, Brazil. I build **LLM agents**, **document and data pipelines** and the **backend services** that keep them running in production.

- 🦇 **Now:** LLM agents (LangGraph), MCP servers and queue-driven pipelines that turn legal documents into structured data
- 🧠 **Focus:** agent orchestration, retrieval, data modeling, observability and cost control for LLM workloads
- 🎓 Systems Analysis and Development @ Senac PR
- 🏆 1st place, Ideathon Inova Comércio (Sebrae/PR + Senac/PR, 2025)
